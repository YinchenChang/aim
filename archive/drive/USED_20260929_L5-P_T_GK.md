## 1. 落差陳述

單位時間可從裝置 HBM 搬出的位元＝`BW×t`，是守恆量。decode、低 batch 的 arithmetic intensity 有下界：每新 token 須重讀權重（KV 為次項）。一旦 `AI < ridge＝PeakFLOP／BW`，每秒 token 上界是 `BW／V_byte`，不是 TFLOPS。錯價只在市場把「下一代 PeakFLOP 翻倍」或「容量 GB」當成該上界的代理。測一已把 BW 與 `V_byte` 寫成同一單位；本卡不重開該對帳。C-P1、L5-A、L5-I 不是本格。
