## 1. 落差一句（生成物 → 候選陳述）

市場把代工／封裝「預付款餘額」或「供給與產能承諾」讀成已鎖定的產出噸位（或把餘額下降讀成供給緩解）。種子主張：預付買到的是**合約性排序／保留權**，不是產能物權；條件後續滿足時，處理是退款或抵應收，由雙方同意決定。需求下修時，預付方承擔沒入、短少費、或無法按原排序取片的損失；賣方側可見的是合約負債／暫收款，不是已交付晶圓。錯價只在把「預付餘額＝已持有產能」或「承諾美元＝可分離之晶圓取用權」當成充分統計。

## 2. 機制型態

| 項 | 內容 |
|---|---|
| 型態 | 合約性取用權（預付換排序／保留，非所有權；損失在需求下修時落在預付方） |
| 選擇者 | 晶圓代工／先進封裝賣方對設計商（或 IDM 對戰略客戶）之容量配置 |
| 可見端 | 合併「預付款／合約負債／暫收款」餘額；「供給與產能承諾」美元；LTA 剩餘營收承諾；法說「與客戶提前規劃產能」一句 |
| 指名不可見端 | 預付所對應之節點／封裝層／期間；需求下修時退款 vs 抵帳 vs 沒入之契約規則；排序權與實際出貨之對帳 |
| 主張 | 預付↑ 只證明保留權被買走，不證明產出已屬預付方；下修時損失不自動出現在賣方減值科目 |
| 表達工具型態（只指名，不選券） | 已上市、美股可交易之代工、IDM 或設計商揭露主體；預付／暫收款為既有資產負債表或承諾附註。台股上市本體不入表達集 |
| 重疊 | L2-I（法定取用權）；L3-A（單價恆等）；L3-P（物理產能上界）；GFS／MU 之 take-or-pay 與記憶體戰略長約。重疊不構成丟棄 |

契約式（生成用，非正式載入）：

`預付 → 保留權／排序，不 → 產能所有權`；`需求下修 ⇒ 損失 ∈ 預付方（沒入／短少費／排序失效）`。

## 6. 轉入個股層時必問（§7-4，本輪不答）

1. 財報科目：暫收款／保留費能否從合約負債與存貨預付再拆；設計商承諾能否拒絕記憶體與雲協議。
2. 可交易工具：恆等落在美股可交易揭露主體，而非僅台股上市本體或無申報之私有代工。
3. 半衰期：一旦附註把退款規則寫死或 take-or-pay 把空置轉回賣方，≥12 個月窗內「預付方承擔全部損失」是否被契約抵銷。
